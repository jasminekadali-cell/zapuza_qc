# Zapuza Factory Quality System

**Video Demonstration Link:** https://drive.google.com/file/d/1IOJxBZVItQHriGK-KcgLuSFvaRRsxJaI/view?usp=sharing

**4 Functionalities Built:**
1. Database models for Factory Structure (Machine Tools)
2. Raw Material Intake forms
3. Shift Handover logs
4. Supervisor Dashboard for quality approvals

**How to run this project locally:**
1. Open terminal and run: `pip install django`
2. Run: `python manage.py runserver`
3. Open a browser and go to `http://127.0.0.1:8000/admin`
